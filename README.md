# 行业轮动策略复现（分享版）

这是一个精简的可运行版本，用于分享当前已经完成的行业动量轮动实验。仓库只保留核心策略代码、配置、依赖和最终结果，不包含研究过程中的任务文件和中间记录。

## 策略

- 使用历史当日真实存在的股票构建行业股票池；
- 行业信号：过去 10 个交易日累计收益；
- 每天选择动量最高的 Top 3 行业；
- Top 3 行业等权；
- 行业内按自由流通市值加权；
- T 日收盘生成信号，T+1 开盘买入，T+2 收盘卖出；
- 使用两个错开 1 天的子组合，使每天都能执行一组信号；
- ST 股票是否剔除可配置；
- 已持仓股票如果计划卖出日停牌，则继续持有，恢复交易后的第一个可交易日开盘卖出。

## 当前完整历史实验

完整数据范围为 2010-01-04 至 2026-02-13；正式策略回测从 2012-01-04 开始。

### 低成本复刻参数

买入费率 0.0086%，卖出费率 0.0086%，无印花税。

| 指标 | 包含 ST | 剔除 ST |
|---|---:|---:|
| 最终净值 | 21.5524 | 15.6350 |
| 年化收益 | 25.3140% | 22.3926% |
| 最大回撤 | -31.3112% | -29.5438% |
| Sharpe | 1.0176 | 0.9175 |

### 交易成本压力测试

按买入费率 0.03%、卖出费率 0.03%、卖出印花税 0.10%（完整一轮约 0.16%）重新回测：

| 指标 | 包含 ST | 剔除 ST |
|---|---:|---:|
| 最终净值 | 1.9211 | 1.4089 |
| 年化收益 | 4.9151% | 2.5513% |
| 最大回撤 | -48.1515% | -56.1172% |
| Sharpe | 0.3164 | 0.2266 |

可见策略的毛收益较强，但两日轮动造成极高换手，真实交易成本会显著侵蚀收益。详细结果见 `RESULTS.md`。

## 文件

- `prepare_data.py`：把股票日 K CSV 转成 DuckDB 缓存；
- `run_backtest.py`：事件驱动回测；
- `config.example.yaml`：配置模板；
- `requirements.txt`：Python 依赖；
- `RESULTS.md`：当前实验结果；
- `sample_data/`：后续上传约 2–3 个月的小样本数据，便于直接测试代码。

## 运行

```bash
pip install -r requirements.txt
```

复制配置：

```bash
cp config.example.yaml config.yaml
```

Windows PowerShell 可用：

```powershell
Copy-Item config.example.yaml config.yaml
```

如果使用本仓库样本数据，把 `config.yaml` 中 `data_root` 指向 `./sample_data`，然后：

```bash
python prepare_data.py --config config.yaml
python run_backtest.py --config config.yaml
```

样本数据只有约 2–3 个月，因此只能用于验证代码和观察短期运行过程，不能复现 2012–2026 的完整历史净值。

## 说明

当前行业收益不是官方申万行业指数历史序列，而是基于历史时点可交易股票按自由流通市值动态重建。代码默认允许小数股，以尽量逼近指数/资金权重；若要做真实 A 股下单约束，可将 `allow_fractional_shares` 设为 `false` 并使用 100 股手数。
